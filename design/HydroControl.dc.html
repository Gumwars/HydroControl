HydroControl · frontend prototype

A control panel that shows the hardware, not the preference file

Built on Nocturne — its compact 0.7× spacing, Inter at 500, 8px radii and outlined actions — with the accent ramp re-seeded from your Matugen wallpaper colour #8CBF73, the way DankMaterialShell re-tints itself. Neutrals carry a faint green cast so the app frame reads as part of the shell. Numeric readouts are JetBrains Mono; status colour is reserved for status only.

Assumptions I made: one user, no onboarding, 2560×1600 panel shown here at a floating-window size on Hyprland; sidebar nav over five sections; live telemetry ticks once a second; radial gauges for the two temperatures, a rolling 60 s line for package power. Drift is shown as subtle inline marks as you asked — a warn dot on the live value plus an inline re-apply, never a modal. Out-of-scope surfaces (fan curves, performance presets) are named as unavailable rather than mocked up as dead controls.
